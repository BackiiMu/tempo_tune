# TempoTune

한국어 기본 지원, 서버·로그인 없이 사용하는 Flutter 악기 연습 도구입니다. 디자인은 제공된 `DESIGN-notion.md`의 따뜻한 회백색, 흰색 카드, 얇은 테두리와 파란색 주요 동작을 적용했습니다.

## 구현한 화면과 기능

- **메트로놈:** 30–300 BPM 직접 입력, ±1/±5, 슬라이더, 8종 박자, 강박/약박, 박별 무음, 3종 클릭, 볼륨, 진동 보조, 재시작, 이름 있는 템포 프리셋 추가·수정·삭제.
- **탭 템포:** 단조 증가 시계, 최근 4–8개 간격, 짧은 중복 입력 방지, 이상치 완화, 2–6초 자동 초기화, 소수점 표시, 마지막 측정 저장, 메트로놈 적용 및 이동.
- **튜너:** 실제 마이크 PCM, YIN 피치 검출, 음이름·옥타브·주파수·cents, 자동/수동 줄 선택, 줄별 완료 표시, 크로매틱, A4 430–450 Hz, 허용 오차 1–15 cents, 샵/플랫 표기.
- **튜닝 데이터:** 6현 기타 8종, 7현 기타 2종, 4현 베이스 4종, 5현 베이스 1종, 우쿨렐레 3종. 사용자 정의 튜닝 추가·수정·삭제. 우쿨렐레의 G–C–E–A 물리적 줄 순서를 유지합니다.
- **설정:** 로컬 저장, 마지막 악기/튜닝 기억 옵션, 마이크 상태, 앱 버전, 초기화.

## 실행

Flutter 3.47.8 / Dart 3.13.7에서 개발·검증했습니다. iOS 최소 15.0, Android 최소 API 24입니다.

```sh
flutter pub get
flutter run -d <device-id>
```

앱 실행에는 네트워크가 필요하지 않습니다. 개발 도구와 패키지를 처음 설치하는 빌드 단계에는 네트워크가 필요합니다. 마이크 권한은 튜너의 **마이크 켜기**를 누를 때만 요청합니다. 녹음은 저장하거나 전송하지 않습니다.

## 네이티브 오디오

### iOS

`AVAudioEngine` + `AVAudioSourceNode`가 48 kHz PCM 프레임을 채웁니다. 3종 클릭의 강박/약박 파형을 재생 전에 합성해 준비합니다. 렌더 콜백 안에서 소수 프레임 누산기로 클릭 위치를 계산하므로 Flutter UI 프레임이나 타이머에 재생이 의존하지 않습니다. 마이크는 `inputNode` tap에서 수집하고 별도 직렬 큐에서 분석용 12 kHz 모노 프레임으로 변환합니다. 오디오 세션 인터럽트·경로 변경·엔진 구성 변경 시 정지하고 재시작을 안내합니다.

### Android

전용 오디오 우선순위 스레드에서 `AudioTrack`의 blocking PCM 버퍼 출력을 사용합니다. `FrameClock`이 출력 프레임 수로 클릭을 배치하며 `Timer.periodic`로 소리를 재생하지 않습니다. `AudioRecord`는 별도 스레드에서 48 kHz PCM을 수집하고 12 kHz로 축소합니다. 오디오 포커스 손실과 장치 변경 시 정지합니다. 이 방식은 하드웨어 버퍼에 맞춰 흐르는 스트리밍 출력이며 Oboe/AAudio 전용 엔진은 아닙니다.

양 플랫폼에서 BPM은 **4분음표 기준**입니다. `/8` 박자는 8분음표마다 클릭하므로 120 BPM의 6/8은 클릭 간격이 0.25초입니다. 6/8·9/8·12/8은 세 박씩 묶고, 7/8은 2+2+3 강세입니다. BPM 변경 시 현재 박의 진행 비율을 보존합니다.

UI 박 표시와 진동은 네이티브 이벤트를 받아 갱신하므로 출력 지연을 포함하지 않는 시각적 보조입니다. 블루투스 및 OS 버퍼 지연을 보정했다고 주장하지 않습니다.

## 피치 검출

분석은 Dart worker isolate에서 수행합니다. 12 kHz / 4096 샘플(약 341 ms) 프레임에 DC 제거, RMS 게이트, YIN 차분 함수와 누적 평균 정규화를 적용합니다. 임계값 0.15로 주기 후보를 고르고 원 차분 함수의 포물선 보간으로 주파수를 추정합니다. 최근 3개 검출의 중앙값과 음정 변화 시 이력 초기화로 흔들림을 완화합니다. 무음·비주기성 입력에서는 음정을 표시하지 않습니다.

검출 범위는 약 27–1500 Hz입니다. 사용자 정의 음정은 A0–F#6 범위로 제한합니다. B0/E1은 합성 신호 테스트를 통과했지만 실제 저음 검출 성능은 마이크, 주변 소음, 악기 배음에 영향을 받습니다. 고정 RMS 게이트와 신뢰도 필터를 사용하며 별도의 학습형 잡음 제거 기능은 없습니다.

## 폴더 구조

```text
lib/
  app/                         앱 셸, 공통 UI, 수명주기, 기능 연결
  core/audio/                  MethodChannel / EventChannel 계약
  core/storage/                공유 상태 및 설정 저장
  features/metronome/           메트로놈 화면
  features/tap_tempo/           탭 계산 도메인 및 화면
  features/tuner/               튜닝 데이터, 독립 DSP, 튜너 화면
  features/settings/            설정 화면
android/app/src/main/kotlin/    AudioTrack, AudioRecord, FrameClock
android/app/src/test/kotlin/    네이티브 프레임 타이밍 테스트
ios/Runner/AppDelegate.swift   AVAudioEngine, 마이크 tap, FrameClock
integration_test/              네이티브 출력/입력과 화면 실행 테스트
tool/test_native_clock.py       실제 Swift FrameClock의 실행형 테스트
docs/screenshots/              iOS 실행 화면
```

화면 코드는 공통 상태를 사용하는 Dart library part로 기능별 파일에 분리했습니다. DSP와 탭 계산은 UI에 의존하지 않습니다.
