### 프레임 스케줄링 시뮬레이션

Swift와 Kotlin의 실제 프레임 계산기를 각각 실행했습니다. 각 BPM마다 30분 분량의 48 kHz 프레임을 계산했습니다. 실제 시간을 30분 동안 재생한 검사는 아닙니다.

| BPM | 30분 박 수 | 최대 누적 위치 오차 |
| --- | --- | --- |
| 60 | 1800 | 0 프레임 |
| 120 | 3600 | 0 프레임 |
| 180 | 5400 | 0 프레임 |
| 137 | 4110 | 1 프레임 이내 (약 20.8 μs) |

4/4 박 순서, 6/8의 8분음표 간격 및 3+3 강세, 7/8의 2+2+3 강세, 박 중간의 120→180 BPM 변경 시 위상 보존도 검증했습니다. 이 결과는 출력 기기·드라이버의 underrun이나 실제 스피커 파형을 측정한 결과가 아닙니다.

### 네이티브 재생 이벤트의 관측 간격

실제 네이티브 오디오 경로를 시작하고 Flutter에 전달된 이벤트 간격을 단조 증가 시계로 관측했습니다. 예열 후 3개 간격의 평균이며 허용 오차는 ±0.1초입니다.

| BPM | 목표 간격 | iOS 27.1 시뮬레이터 | Android 에뮬레이터 |
| --- | --- | --- | --- |
| 60 | 1.000초 | 1.00272초 | 0.99774초 |
| 120 | 0.500초 | 0.50116초 | 0.52195초 |
| 180 | 0.33333초 | 0.33408초 | 0.34020초 |

UI 전달 및 에뮬레이터의 스케줄링 지터가 포함된 수치입니다. 실제 출력 파형의 클릭 간격이나 하드웨어 지연으로 해석하면 안 됩니다. Android에서는 AudioRecord에서 전달된 실제 PCM 프레임이 4096개의 유한한 숫자 샘플인지 확인했습니다. 에뮬레이터 입력이 실제 악기 소리라는 의미는 아닙니다.

### 튜너 DSP

- 생성한 사인파: B0 약 30.87 Hz, E1 약 41.20 Hz, E2 약 82.41 Hz, 432/440/442/880 Hz를 2 cents 이내로 검출.
- 440 Hz → A4, 0 cents; 442 Hz → +7.85 cents; 432 Hz → −31.77 cents.
- 기본음보다 두 번째 배음이 큰 E2 합성 신호와 소량 잡음을 더한 입력 검출.
- 무음, 작은 신호, 난수 잡음에서 유효 피치 표시 방지.
- 실제 앱과 같은 worker isolate 호출 경로에서 E1 검출.
- 18개 튜닝 데이터의 음정 범위, 기타/베이스 줄 순서, 우쿨렐레의 re-entrant G–C–E–A 순서 검증.

실제 악기 녹음 샘플은 제공되지 않았고 이 환경에서 수집하지 않았습니다. 녹음 샘플로 검증했다고 보고하지 않습니다.

## 빌드

- iOS 시뮬레이터 디버그 빌드 성공. 화면 통합 테스트에서 설치·실행 확인.
- Android 디버그 APK 최종 빌드 성공: `build/app/outputs/flutter-apk/app-debug.apk`. 에뮬레이터 설치·실행 확인. 최종 APK는 통합 테스트가 아닌 `lib/main.dart` 진입점입니다.
- iOS 실제 기기용 **무서명 릴리스 빌드 성공**: `build/ios/iphoneos/Runner.app` (16.7 MB). 물리 기기에 설치하거나 실행한 결과는 아닙니다.
- Android 배포용 release 서명·AAB와 iOS 서명·Archive·TestFlight 배포는 수행하지 않았습니다.

이 환경의 Java 인증서와 macOS 시스템 키체인 차이로 첫 Android 빌드가 실패했습니다. 공식 Gradle 배포 파일의 SHA-256을 검증하고, macOS 시스템 신뢰 인증서로 만든 임시 Java trust store를 사용해 해결했습니다. TLS 인증서 검사를 비활성화하지 않았습니다. 누락된 NDK 28.2 및 SDK Platform 35도 빌드 과정에서 설치되었습니다.

## 미검증 및 제한

1. **실제 기기/악기:** 연결된 사용자 휴대폰에는 설치하거나 마이크를 켜지 않았습니다. 스피커 파형을 외부 녹음한 타이밍 검사, 실제 기타·베이스·우쿨렐레, 기기별 E1/B0 저음 성능은 추가 검증이 필요합니다.
2. **iOS 마이크:** iOS 27.1 시뮬레이터가 유효한 마이크 입력 포맷을 제공하지 않아 입력 통합 테스트는 실패했습니다. 앱은 '마이크를 사용할 수 없어요' 오류를 반환했습니다. iOS 실제 기기의 PCM 수집/피치 표시는 미검증입니다.
3. **이전 iOS 시뮬레이터:** iOS 26.5 런타임에서는 CoreAudio가 출력 포맷을 0 Hz로 보고하고 초기화 중 RPC timeout으로 종료되는 현상이 있었습니다. 최신 27.1 런타임의 출력 테스트는 통과했습니다. 유효 출력 검사와 엔진 구성 알림의 재진입 방지를 추가했으나 모든 이전 런타임 문제가 해결되었다고 주장하지 않습니다.
4. **중단/권한:** 앱 수명주기, 오디오 포커스·세션 인터럽트, 경로 변경, 권한 거절 안내/앱 설정 이동 처리는 구현했습니다. 실제 전화, 다른 음악 앱, 이어폰/블루투스 연결 변화, 권한 영구 거절과 복귀의 전체 조합은 물리 기기에서 검증하지 않았습니다.
5. **백그라운드:** 재생/튜닝을 정지하고 오디오 리소스를 해제합니다. 백그라운드 메트로놈 서비스는 구현하지 않았습니다.
6. **지연/정확도:** 블루투스 지연 보정, 하드웨어 latency 측정, 장시간 실제 재생 중 underrun·배터리·발열·CPU 측정은 미수행입니다. UI 이벤트와 진동은 정확한 오디오 타이밍의 대체 수단이 아닙니다.
7. **튜너:** 단일음 전용, 약 27–1500 Hz, 고정 RMS 게이트. 주변 소음이 강하거나 기본음이 거의 없는 악기에서 옥타브 오인식이 남을 수 있습니다.
8. **출시:** 기본 개발용 bundle/application ID와 디버그 서명을 사용합니다. 정식 출시 식별자·배포 인증서·스토어 설정은 미설정입니다.

```sh
flutter build apk --debug
```
